# 観察結果と不具合の報告

確認結果は、対象・パッケージ ID・版・Unity／SDK 版・環境・操作・期待結果・実際の結果・再現率・ログ／画像を一組で記録します。仕様上の制約、導入失敗、実行時の不具合、使いにくさは区別します。期待結果には配布元ドキュメントの該当箇所をリンクします。

このリポジトリの [Issue テンプレート](https://github.com/sabas0ba/test_vrc_sabax/blob/main/.github/ISSUE_TEMPLATE/observation.md) を使って一次記録を残します。再現を確認した不具合は対象の上流リポジトリへ報告し、相互リンクします。公開リスティングとソースの差だけでは不具合と断定しません。未実施のケースは [対象一覧](status.md) の「未実施」のままにします。

利用例として公開する際は、動作条件、手順、実際の結果、既知の制約を同じページに置きます。ログにアカウント情報やローカルパスが含まれる場合は公開前に除去します。
